# CLAUDE.md — The Cat's Pajamas Club («Пижама Кота»)

> **Обзор проекта — `../HANDOFF_CATS_PAJAMAS.md`** (стек, прод, модель данных,
> карта документов). **Активный план работ — `../HANDOFF_RESTYLE.md`.**
> Этот файл — только правила визуала и Definition of Done.

Сайт джаз-бара: React 18 + Vite, чистый CSS (весь в `src/index.css`, ~2300
строк), grammY-бот, self-hosted Supabase. Лендинг — **обычная скроллящаяся
страница** (редизайн 2026-07-08, коммит `6343f91`; прежняя «книга» с
3D-перелистыванием удалена): фикс-шапка `Nav.jsx` сверху, секции
`Hero → Легенда → Стена памяти → Бармены → Меню → Афиша → Как найти → Футер`
растут по контенту. Номер главы в `sec-label` каждой секции — сквозной, при
вставке новой секции перенумеровать ВСЕ следующие (RU и EN в `src/data.js`).
Фон первого экрана — WebGL-атлас `ui/SilkBackground.jsx` (Silk с
reactbits, выбран владельцем 2026-08-22; слайд-шоу из фотографий убрано).
Reveal-анимации — `useReveal` (наблюдатель + страховочный проход по
геометрии); WebGL-фон сам встаёт на паузу вне экрана через `ui/glHost.js`,
для CSS-анимаций тот же приём даёт `useOffscreenPause` (класс `is-offscreen`).
Hover всех кликабельных элементов — один примитив `.u-glare` (§C.2).

## Правила визуала — нарушение = баг, даже если «выглядит нормально»

Каждое правило выстрадано реальным багом этого проекта (история — в
`../docs/archive/`).

### Анимации
Свободная зона: эффекты выбираем по вкусу (в т.ч. готовые с reactbits.dev),
прежних запретов на свойства/бесконечные анимации/backdrop-filter больше нет
(снято по решению владельца 2026-08-22). Жёстких правил осталось два, и оба
не про эстетику:
- **Внутри `.fp-svg` (план зала) — ноль animation/transition.** Профилировано:
  любая анимация в этом SVG перерисовывает весь план каждый кадр (фризы на
  слабых машинах). Всё живое — HTML-оверлеями поверх (образец `.bkw__glowbar`).
- У каждой новой анимации — ветка `prefers-reduced-motion` (доступность,
  паттерн по всему CSS).

Если после нового эффекта появится рябь, фриз или «съеденная» батарея —
причины прошлых таких багов и их разбор лежат в истории git (коммиты про
шапку и reveal от 2026-08-22) и в `../docs/archive/`.

### Layout
- Секция-экран — `min-height: 100svh/100dvh`, НЕ `height: 100vh` +
  `overflow: hidden` (молча режет контент на коротких экранах — чинили).
  Секции скролл-лендинга растут по контенту — не зажимать их обратно.
- **Safe-area обязательна:** в `index.html` стоит `viewport-fit=cover`;
  фиксированные элементы у краёв экрана — только с отступами
  `env(safe-area-inset-*)`.
- Fixed-инвентарь: шапка `.nav` (сверху). Новые fixed-элементы — проверить,
  что не пересекаются с ней и с системными зонами на трёх высотах экрана.
- Брейкпоинт бургер-меню — 900px, не опускать (на 768px полная навигация
  не помещается — чинили).
- Проверять desktop и на низкой высоте (1366×700), не только на высоком
  мониторе.

### Дизайн-система (тема AMBER NIGHT, `[data-theme="A"]`)
- Палитра — по логобуку («Пижама кота_логобук.pdf», стр. 29): фон `--bg`
  #1C101A / `--bg2` #250F21, текст `--text` #C6BFB5, акцент-золото
  `--accent`/`--gold` #B08900. Цвета/отступы/радиусы — ТОЛЬКО токены из
  `[data-theme]`; голый hex в правке — баг. Новые фирменные цвета
  (#371931 графика, #857861 пастель, #29281E олива) подключать новыми токенами.
- **Золото — акцент для деталей** (подписи, ссылки, CTA), не заливка крупных
  площадей — правило логобука (стр. 30).
- Роли шрифтов (жёстко, логобук стр. 27–28): **Baskerville** — заголовки;
  **Involve italic** — подзаголовки/теглайны; **Avenir Next** — текст;
  **Jar Binks** — ТОЛЬКО прямые цитаты людей (`.about__quote`, `.team__quote`),
  кегль ≥ 28px. Jar Binks на заголовках/навигации/названиях — прямое
  нарушение требования заказчика. Длинное тире в Jar Binks рендерится
  жирной чертой — не использовать в цитатах.
- Фирменная графика (паттерн бутылок, арт-деко рамки, знак-креманка) — правила
  применения в `../HANDOFF_RESTYLE.md` §бренд и §C.
- Тексты UI двуязычные (RU/EN) в `src/data.js` — переименования синхронно в
  обоих языках. Контент из БД — только RU.
- **Фото «Стены памяти» не хардкодятся.** Владелец кладёт снимки в
  `public/uploads/showcase/` (в git не ходит), а `npm run dev|build` через
  `scripts/generate-gallery-manifest.mjs` жмёт их в webp двух размеров в
  `public/uploads/showcase-web/` (вот это коммитим) и собирает
  `src/data/galleryPhotos.generated.json`. Имя файла — источник правды:
  `{тег}_{номер}__{исходное}.jpg`, тег группирует кадры одного человека.
  Руками список не править — перезатрётся.

## Визуальная проверка — обязательна

После каждой значимой правки: `preview_start` (конфиг `cats-pajamas-club`,
порт 5173) → скриншоты mobile/tablet/desktop + низкая высота (~700px) →
осмотреть глазами. Известная особенность: `preview_screenshot` иногда
зависает — не блокироваться, проверять связкой `preview_inspect` (вычисленные
стили) + `preview_snapshot` (структура). Полный чеклист «готово» — скилл
`web-polish` (`references/checklist.md`); пока не пройден — задача не готова.

## Границы

**Одна сессия ведёт весь проект** — сайт, бот, API, БД (решение владельца).
- Функциональные маршруты `/booking`, `/admin`, `/profile`, `/auth`, `/menu` —
  готовые системы; работая над лендингом, не ломать ссылки на них.
- Секции Menu/Events/Team тянут контент из API — не заменять хардкодом;
  `.catch(() => setX([]))` — секция не крашится без API.
- В навигации сохранять: вход через Telegram/профиль, кнопку «Админ-панель»
  (видна только админам), CTA на `/booking`.
- При правках бота — переиспользовать `api/_lib/*`, не дублировать логику,
  не ломать флоу (бронь, отзывы, события, auth, рассылка).
- `Booking.jsx`, `PageBackdrop.jsx`, `Shelf.jsx` не смонтированы (наследие
  редизайна / «полка в разработке») — не удалять молча.

## Деплой

Прод один — VPS (`https://cats-pajamas.ru`), деплой `bash deploy.sh` строго с
локальной машины, атомарный (releases/<ts> + симлинк `dist_current`).
**Не деплоить без явной просьбы.** Runtime-загрузки хранить вне релизов
(см. `../HANDOFF_RESTYLE.md` §B). Схему БД применять руками (мастер-док §прод).

## Definition of Done

`npm run build` чистый (включая оба пререндера); чеклист web-polish пройден;
скриншоты/inspect на 4 вьюпортах осмотрены; интеграции живы: вход через
Telegram, CTA на `/booking`, данные Menu/Events/Team с бэкенда; при правках
бота — `node devtools/bot_e2e.mjs` = ALL PASS.
